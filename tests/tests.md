# 自动化测试速查

## 职责与文件

当前目录没有子目录。使用 Node 内置 `node:test` 和断言，覆盖真实业务分支及生命周期回归；不引入额外测试框架。

- `windowed-list.test.cjs`：真实模板编译、窗口数量与完整高度、动态行高和滚动锚点、排除动画变换的测量、断点重测、焦点保留、双向 Tab、KeepAlive 清理恢复及筛选空结果。

- `details-motion.test.cjs`：原生折叠区关闭后再收起内容、快速反向与旧完成回调隔离、动态内容缩小、减少动态效果即时收敛，以及嵌套按钮语义和监听释放。

- `renderer-state.test.cjs` 还验证账号目录请求复用、迟到响应隔离、登录缓存代次和旧账号失效响应不登出新账号；`player.test.cjs` 覆盖桥段前句、前奏及两种进度条拖动期间的实时预览、播放时间回传保护、取消恢复和提交后的平滑滚动；桥段编舞覆盖暂停帧稳定、预览优先级与取消、前奏/短 KRC 桥段收拢及结束边界、浏览定位不改变播放形态。

## 执行与边界

在项目根目录执行已验证的 `npm test`。Node 自动发现 `.test.cjs`，部分渲染模块通过现有编译器或内存转译加载；Electron、浏览器与文件系统副作用使用受控 Mock 验证。

API 测试启动临时本地 HTTP Server，结束时关闭连接、监听和缓存。测试只使用占位凭证，不访问用户账号或真实酷狗认证接口。

`npm run check` 同时检查测试源码语法和本地引用。测试不等同于真实 Electron 窗口、音频设备、安装包或外部音乐服务验证；修改这些行为时仍须运行相应场景，并停止本次启动的临时服务。
