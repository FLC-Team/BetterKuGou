# 自动化测试速查

## 职责与文件

当前目录没有子目录。使用 Node 内置 `node:test` 和断言，覆盖真实业务分支及生命周期回归；不引入额外测试框架。

- `settings-store.test.cjs`：主进程设置事务、失败回滚、并发合并、危险字段及自启兼容。
- `desktop-settings.test.cjs`：桌面歌词初始化前打开、已提交偏好广播、暂停时间与歌词首屏重放、换曲清空、IPC 发送方/枚举校验及已挂载歌词的翻译同步。
- `backend-service.test.cjs`：后端立即探测、连接拒绝/503 重试、共享就绪等待、启动截止与真实本地 HTTP，以及请求销毁、停止去重、定时器/监听释放、旧实例保护及强制退出分支。
- `update-worker.test.cjs`：SemVer 与正式/测试筛选、分页及平台架构匹配、代理与 GitHub 成功/失败/超时、响应与重定向边界、流式下载大小/SHA256、缓存复用与损坏替换、取消/磁盘错误不换源、进度节流、路径约束、请求代次及真实 Node Worker 停止。
- `update-service.test.cjs`：启动延迟与每日调度、只消费已提交策略、手动操作立即返回与去重、自动下载及取消后抑制、渠道切换和迟到响应隔离、Worker 异常恢复、已下载包复核、共享退出清理及超时结束线程。
- `app-updates.test.cjs`：实际编译 Vue 模板挂载、原生布尔 disabled 语义、浏览器禁用、版本显示、先订阅与快照竞态、保存失败和等待、来源/进度/错误、资产选择、下载中重开及取消后重试、手动安装确认去重与取消、AppImage 只定位及完成后切换 DEB、更新说明纯文本和固定发布页入口。
- `update-integration.test.cjs`：开发/打包 Worker 路径、主窗口顶层 IPC、更新策略迁移与非法字段过滤、成功保存后配置服务、原生确认前后文件复核、包改变/损坏阻止打开、AppImage 不执行、连续安装与退出失效，以及启动/下载完成/退出均不自动安装。
- `object-utils.test.cjs`：对象合并和响应式替换的危险字段拒绝、数组替换与引用保持。
- `main-lifecycle.test.cjs`：无固定延时的主窗口创建、仅主窗口顶层页面挂载后显示及启动期间播放指令冲刷、启动中退出、托盘模式主动退出、并发清理、窗口隔离、定时器释放和初始化失败关闭路径。
- `startup.test.cjs`：运行真实渲染入口，验证设置与后端任一完成顺序、读取失败仍等待另一任务、无桥接浏览器预览及挂载后首帧就绪通知。
- `preload.test.cjs`：白名单桥接、事件隐藏、订阅解绑和播放时间输入边界。
- `install-quit-service.test.cjs`：真实本机命名管道能力探测、保存确认后退出、断开/超时/失败/并发取消及资源释放。
- `install-quit-integration.test.cjs`：仅 Windows 打包版启动协作、主窗口顶层 frame/请求代次、重载/崩溃取消与保存中托盘操作拦截。
- `installer-packaging.test.cjs`：真实 Linux 产物命名、两类发布上传规则、更新器架构识别及 DMG/NSIS 配置与资源尺寸。
- `installer-nsis.test.cjs`：提取实际安装器函数编译执行，验证完整 SemVer 的 29 组优先级与非法版本，以及真实 Win32 管道成功保存退出通信、错误服务器 PID/安装路径拒绝、读取 SAVED 并关闭句柄；非 Windows 或缺少编译器明确跳过，Windows CI 打包后要求实际运行。原生探针限时 3 秒，不安装、不操作注册表，临时文件及进程自动清理。
- `renderer-state.test.cjs` 同时覆盖安装前等待草稿/会话/持久化、保存失败恢复、取消后迟到结果失效及保存期间异步切歌重新采样。
- `logger.test.cjs`：日志级别、敏感数据处理及日志保留边界。
- `api-server.test.cjs`：本地 HTTP 参数映射、查询优先级、缓存隔离、脱敏和服务启动异常。
- `renderer-state.test.cjs`：启动设置并发读取及失败回退、真实 Vue 异步页 KeepAlive/ref 保持，以及渲染设置提交与回滚、设置页保护播放会话、认证缓存、搜索竞态、快捷键及根组件清理。
- `login.test.cjs`：登录轮询、异步结果及资源释放。
- `favorites.test.cjs`：收藏与普通歌单的目录复用、请求去重、局部刷新、分页失败保留、账号/请求失效、缓存归属及本地编辑保护；925 首跨页检索、页长限制与缺少总数不漏项、重复满页终止且保留合法重复曲目、查询独立缓存、过滤与排序不改变全量队列及右键歌曲对象。
- `song-metadata.test.cjs`：VIP 权限数字/字符串与历史字段兼容、未知权限不误标，歌曲/歌手/专辑检索兼容且保留原行对象。
- `page-cache.test.cjs`：歌手初始化失败后可继续加载单曲/专辑；首页首次请求去重、失败模块补拉、成功空结果缓存、推荐种子变化及跨日请求合并。
- `player.test.cjs`：播放器、歌词、播放列表及卸载；覆盖选歌、前后切歌、随机、自动续播与优先队列的过渡意图，排队选歌覆盖、失败和同首重播的动画状态保护，以及进度预览与提交、跳转/桥段/末句、长句内层同步及动画帧释放，歌词离场通知时机、快速重开及关闭后异步请求失效。

## 执行与边界

在项目根目录执行已验证的 `npm test`。Node 自动发现 `.test.cjs`，部分渲染模块通过现有编译器或内存转译加载；Electron、浏览器与文件系统副作用使用受控 Mock 验证。

API 测试启动临时本地 HTTP Server，结束时关闭连接、监听和缓存。测试只使用占位凭证，不访问用户账号或真实酷狗认证接口。

`npm run check` 同时检查测试源码语法和本地引用。测试不等同于真实 Electron 窗口、音频设备、安装包或外部音乐服务验证；修改这些行为时仍须运行相应场景，并停止本次启动的临时服务。
