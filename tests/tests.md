# 自动化测试速查

## 职责与文件

当前目录没有子目录。使用 Node 内置 `node:test` 和断言，覆盖真实业务分支及生命周期回归；不引入额外测试框架。

- `settings-store.test.cjs`：主进程设置事务、失败回滚、并发合并、危险字段及自启兼容。
- `desktop-settings.test.cjs`：桌面歌词初始化前打开、已提交偏好广播、暂停时间与歌词首屏重放、换曲清空、IPC 发送方/枚举校验及已挂载歌词的翻译同步。
- `backend-service.test.cjs`：后端健康检查、请求销毁、停止去重、定时器/监听释放、旧实例保护及强制退出分支。
- `object-utils.test.cjs`：对象合并和响应式替换的危险字段拒绝、数组替换与引用保持。
- `main-lifecycle.test.cjs`：托盘模式主动退出、并发清理、窗口隔离、定时器释放和初始化失败关闭路径。
- `preload.test.cjs`：白名单桥接、事件隐藏、订阅解绑和播放时间输入边界。
- `logger.test.cjs`：日志级别、敏感数据处理及日志保留边界。
- `api-server.test.cjs`：本地 HTTP 参数映射、查询优先级、缓存隔离、脱敏和服务启动异常。
- `renderer-state.test.cjs`：渲染设置提交与回滚、设置页保护播放会话、认证缓存、搜索竞态、快捷键及根组件清理。
- `login.test.cjs`：登录轮询、异步结果及资源释放。
- `favorites.test.cjs`：收藏与普通歌单的目录复用、请求去重、局部刷新、分页失败保留、账号/请求失效、缓存归属及本地编辑保护；925 首跨页检索、页长限制与缺少总数不漏项、重复满页终止且保留合法重复曲目、查询独立缓存、过滤与排序不改变全量队列及右键歌曲对象。
- `song-metadata.test.cjs`：VIP 权限数字/字符串与历史字段兼容、未知权限不误标，歌曲/歌手/专辑检索兼容且保留原行对象。
- `page-cache.test.cjs`：歌手初始化失败后可继续加载单曲/专辑；首页首次请求去重、失败模块补拉、成功空结果缓存、推荐种子变化及跨日请求合并。
- `player.test.cjs`：播放器、歌词、播放列表及卸载；覆盖选歌、前后切歌、随机、自动续播与优先队列的过渡意图，排队选歌覆盖、失败和同首重播的动画状态保护，以及进度预览与提交、跳转/桥段/末句、长句内层同步及动画帧释放，歌词离场通知时机、快速重开及关闭后异步请求失效。
- `playback-quality.test.cjs`：普通音质与本地端点映射、API 参数、真实格式/码率判定及渲染/主进程偏好补全和非法导入校验。`player.test.cjs` 还覆盖换质的最新位置与暂停保留、歌词/动效保持、权限/播放/解码失败回滚、快速连选、与选歌交错、停止/卸载取消和保存失败重试。
- `theme-packages.test.cjs`：主题 JSON 往返、白名单及文件/尺寸边界、资源/原型/循环拒绝、坏包回退、完整切换、系统监听和导出隐私边界。
- `theme-customization.test.cjs`：高级 CSS AST 解析及资源/脚本/选择器拒绝、条件与伪元素作用域、规范化/JSON 转义后体积边界、区域覆盖写入和恢复继承、全量令牌/双窗口主题分享持久化、预览广播隔离与取消/切换清理、独立桌面歌词 style/令牌替换移除。
- `renderer-state.test.cjs` 还覆盖外观恢复握手：清除主题字段草稿并保留其他偏好、等待已有保存并丢弃期间的主题编辑、恢复保存失败后不重放旧坏主题。
- `renderer-state.test.cjs` 同时验证播放会话广播不回退尚未保存的主题预览。
- `renderer-state.test.cjs` 还覆盖设置保存失败保留草稿与重试、慢保存期间的后续编辑、主进程规范化结果、导出前保存及导入导出失败反馈；`theme-packages.test.cjs` 覆盖精调完整继承、范围与颜色校验、恢复默认、独立 ID 及安装上限。
- `player.test.cjs` 还覆盖音频真正播放后才提交过渡、异步歌词阶段与当前时间定位、快速 A→B→A 的行引用隔离，以及旧封面错误保护；全屏 CSS 动效通过实际 Electron 渲染另行验证。
- `player.test.cjs` 使用真实 Vue watcher 与可延迟 play Promise 验证过期播放成功/拒绝后的已提交音源回滚、后继播放失败、父级会话回写、恢复期间连续选歌、暂停与最新位置保留、首次无旧源、歌词失效补拉及同首重播；停止/卸载后迟到播放与恢复不得复活音源，停止后仍可加载新选择。
- `renderer-state.test.cjs` 还验证账号目录请求复用、迟到响应隔离、登录缓存代次和旧账号失效响应不登出新账号；`player.test.cjs` 覆盖桥段前句、前奏及两种进度条拖动期间的实时预览、播放时间回传保护、取消恢复和提交后的平滑滚动。

## 执行与边界

在项目根目录执行已验证的 `npm test`。Node 自动发现 `.test.cjs`，部分渲染模块通过现有编译器或内存转译加载；Electron、浏览器与文件系统副作用使用受控 Mock 验证。

API 测试启动临时本地 HTTP Server，结束时关闭连接、监听和缓存。测试只使用占位凭证，不访问用户账号或真实酷狗认证接口。

`npm run check` 同时检查测试源码语法和本地引用。测试不等同于真实 Electron 窗口、音频设备、安装包或外部音乐服务验证；修改这些行为时仍须运行相应场景，并停止本次启动的临时服务。
