# 安装界面与品牌资源

`windows.nsh` 通过 electron-builder 的 NSIS include 定义安装范围、设置、更新说明和完成页面。权限提升、卸载器生成、注册表和快捷方式沿用 builder 引擎。

`windows-functions.nsh` 在 builder 的 `customHeader` 阶段加载运行函数，确保安装范围宏及插件路径已经就绪；包含界面、SemVer 比较、UTF-8 说明读取和退出管道客户端。

`install-mode.nsh` 在安装/卸载欢迎页展开前及 `customHeader` 阶段幂等替换 builder 的当前用户路径宏。Windows 已知目录通过有长度上限且遇 NUL 停止的 `lstrcpynW` 读取，随后释放原 CoTaskMem；不得用 NSIS 字符串容量对操作系统返回的小缓冲区做固定长度拷贝。保留已有安装记录、重定向的用户程序目录、失败时的 LocalAppData 回退与 `/D` 路径覆盖，不修改依赖模板。

`windows-install-hooks.nsh` 在 builder 的辅助安装段替换默认解包和旧版卸载调用，`windows-install-section.nsh` 执行检查、严格 ZIP 解包、替换、登记和收尾。`windows-file-helper.nsh` 在安装、卸载共用跨登录会话的文件锁，经固定系统 PowerShell 调用 `windows-files.ps1`，通过 Unicode 文件传回路径和错误。此链路依赖锁定的 builder 模板在旧卸载前展开 `customCheckAppRunning`。

`linux-after-remove.tpl` 供 DEB/RPM 使用。实际卸载时按注册的 `/opt` 程序目标清理命令链接，包管理器升级过程中跳过移除。

## 直接子目录

- `assets/`：Windows 深浅色 Logo 位图及 macOS DMG 背景图。

## 核心流程

首次安装默认当前用户；设置页读取根 `LICENSE`，明确勾选后才能开始。已有安装沿用注册表路径与范围，以完整版本号判断更新、重装和降级；降级必须再次确认。更新说明随包携带根 `updata_log.md`，无需联网。

自定义完成页替代 MUI 默认完成页时，`BKGuiInit` 必须保留 `SetAutoClose true`：实际提取成功后自动进入完成页，不等待进度页已隐藏的“下一步”按钮。此设置不自动启动客户端，失败仍留在错误详情并提供关闭入口。

安装之前枚举同名进程。选定目录的进程通过 `\\.\pipe\BetterKuGou.InstallQuit.v1.<PID>` 请求保存退出，验证管道服务端 PID 和实际可执行路径。其他目录、旧版和无法确认的进程要求用户手动退出。`HELLO/1` 探测 1 秒，`QUIT/1` 保存等待 10 秒，总退出等待 30 秒。解包后、替换前再次确认退出。安装器直接替换程序文件，避开旧卸载器的强制退出逻辑。

发起安装的账户同时有个人和全局记录时阻止继续。提权子进程只识别全局记录，避免把管理员的个人版当作原账户的安装。使用现有应用 ID 和数据目录，完成页由用户选择启动或关闭。静默安装被拒绝，避免绕过许可证与降级确认。

首次选择所有用户时取消管理员授权会停留在范围页。已有全局版升级取消授权会终止安装。首装需要专用空目录，所有用户版使用 Program Files 下受保护的专用目录。目录检查拒绝重解析点、系统目录和不安全路径，空间检查覆盖目标盘与临时盘。

新版先在目标卷的同级工作目录解包，解包或校验失败时原目录保持可用。文件全部就绪后用同卷移动完成替换，保留旧目录直到新版本登记成功。安装阶段的失败通过工作目录记录恢复。旧版或包含额外文件的目录在用户确认后保留为同级备份。卸载使用安装时生成的文件清单，只移除对应文件和清空的子目录，并保留应用数据。

## 界面约束

Windows 基准 760 × 500，按系统 DPI 缩放。224px 品牌栏与右侧内容区使用暖白、墨色和柔紫配色，深色主题映射为暖炭色；高对比度使用系统颜色。所有控件明确使用带 ClearType 的 Microsoft YaHei UI，避免继承安装模板或中文衬线回退字体。页面标题与品牌栏共同标识当前步骤，范围、目录、更新说明和完成信息采用统一的卡片及留白层次。

准备及完成页可通过内容区“移动窗口”入口使用系统移动操作；执行期间关闭与移动被禁用。范围卡片的底板、说明与原生单选框都可选择相同范围，保留键盘焦点、单选互斥和读屏状态。未确认许可证时主按钮禁用，勾选后立即更新实际状态与外观。

控件颜色统一通过 `BKSetColors` 按主题选择编译期 RGB 常量，高对比度使用 `SYSCLR`；不得直接将运行时颜色变量传入 NSIS `SetCtlColors`。文字与卡片使用显式 `EXSTYLE=0` 的原生 STATIC，不能恢复 `NSD_CreateLabel` 默认的 `WS_EX_TRANSPARENT`，否则叠层及原生窗口捕获会丢失文案和底色。品牌底板在同组内容之后创建并启用兄弟控件裁剪，避免遮住 Logo、标题与说明；进度页也遵循这一层级约束。

原生 InstFiles 进度页的右侧正文和页脚使用覆盖完整高度的实色 STATIC 底板，与文字背景共用当前主题；不依赖外层对话框的原生背景色。底板在前景控件之后创建并使用兄弟裁剪，随进度控件统一销毁，不能覆盖真实进度条、动画或按钮。

自定义范围、准备和完成页面以非阻塞 nsDialogs timer 执行 180ms 轻移入场；范围单选状态即时提交，卡片底色和边框沿 8 个编译期色阶在约 160ms 内过渡，快速反选从当前色阶转向最新目标。timer 每帧检查 Windows 客户区动画偏好，高对比度或关闭系统动画时立即到达最终状态；换页、进度页与退出清除 timer，不使用 Sleep，不干预权限或安装/退出协议。

提取页的音乐波形由 Win32 `SysAnimate32` 播放本地静音 RLE8 AVI，25fps、2 秒无缝循环；NSIS 提取 Worker 运行期间不注册或执行动画脚本回调。浅深色分别使用对应背景和柔紫波形，按不大于当前 DPI 的 96/120/144/192 资源居中显示，避免原生控件不缩放 AVI 导致裁切。减少动态效果时显示静帧，高对比度不创建装饰控件，真实进度和文字始终保留。

完成卡片使用约 560ms 的勾形揭示；仅完成自定义页通过 nsDialogs timer 等待页面及外层窗口可见后，取消该 timer 并单次启动原生播放，避免隐藏页提前耗尽短片。立即可点击启动或关闭，不等待动效。InstFiles 的 MUI LEAVE 在实际提取成功或 Abort 后统一停止、关闭并销毁动画；失败立即恢复关闭按钮、同步两处步骤和标题，并让错误详情恢复完整空间。换页、提前退出和资源打开失败也释放控件、内部计时及剪辑缓冲。

深色模式的单选框和复选框通过 `BKChoiceColors` 使用原生经典绘制，避免 Windows 视觉样式忽略浅色文字；卡片选择变化同时更新底板、边框与说明背景，高对比度继续使用系统样式。

所有操作按钮使用原生 Win32 Button 承载统一的扁平圆角位图，按主操作、次操作与轻按钮区分层级，仅用窗口区域裁去外框，保留可访问名称、键盘、按压与内部焦点提示；禁用主按钮使用独立配色，高对比度保留系统原生按钮。进度保留真实 NSIS 进度控件与错误详情，不使用模拟百分比；执行时隐藏底部操作，失败后恢复关闭入口。详情列表在内容区内单独布局，并用 ListView 原生颜色消息适配主题。进度装饰进入完成页时销毁，位图与字体在退出时释放。

macOS 保留 Finder 拖放；DMG 背景说明首次安装与退出后替换。Linux 保留系统包管理器和 AppImage 替换方式。

## 构建

打包入口由根 `package.json` 维护，Windows include 指向 `windows.nsh`。Windows 打包通过构建钩子校验并缓存官方 NSIS 3.12 工具包，CI 用同一编译器运行原生回归。

`windows-architecture.nsh` 在读取安装范围和路径前选择与旧通用包一致的注册表视图，64 位 Windows 上的各架构安装与卸载共用 64 位视图。独立 ARM64 安装包校验系统架构并使用该架构的解包大小检查空间，独立 x64 安装包也支持系统明确启用了 x64 用户态仿真的 ARM64 Windows。

静态图像由 `pwsh -NoProfile -File scripts/generate-installer-assets.ps1` 在 Windows PowerShell 7 下从公共 Logo 生成，附加 `-WindowsOnly` 仅更新 NSIS 深浅 Logo；其他平台直接打包已提交的 640 × 420 与 1280 × 840 DMG 背景。Windows 的实际版本比较由 `tests/installer-nsis.test.cjs` 提取原函数编译并执行验证。

`node scripts/generate-installer-motion.cjs` 使用纯 Node 生成全部静音原生动画资源，无外部编码器或新增依赖；打包直接读取已提交 AVI。

`tests/installer-install-mode.test.cjs` 使用 ReadProcessMemory 的合法范围正控及跨保护页失败负控验证内存边界，不依赖不同 System 插件对访问违规的进程退出码；运行实际路径宏验证安全拷贝及安装目录兼容，并禁止回退到旧的固定宽度指针读取。不执行安装或修改真实安装记录。Windows CI 在打包获得编译器后要求该测试通过。

`tests/installer-completion.test.cjs` 执行真实初始化、进度和完成页面，在临时目录实际提取测试文件，验证成功后无需按键即可进入完成页；测试不自行补设自动跳转，不安装应用或修改已有安装记录。

`tests/installer-ui.test.cjs` 编译实际界面函数及动画 timer，验证实际色阶推进、快速反转、高对比度跳过和页面动画身份清理；使用自有窗口验证控件颜色、Logo、层级、中文字体、卡片及原生单选激活的互斥状态、许可按钮启禁用与外观刷新，并通过私有离屏位图验证标题和深色单选项实际文字像素。进度页测试刻意改变自有宿主背景，采样正文和页脚实际像素并验证底板销毁，避免只检查颜色声明而漏掉背景空隙。额外的非激活自有窗口探针在临时插件目录真实提取测试文件并触发 Abort，通过一次 GetDIBits 取回完整原生帧并计算 SHA256，避免稀疏像素采样遗漏细线变化；验证原生波形帧变化、减少动态静帧、不同 DPI、完成单次播放、失败立即关闭入口、无效资源降级及 HWND 销毁。Windows CI 在打包获得编译器后要求原生测试通过；测试不执行真实应用安装或注册表写入，完整安装及前台视觉检查仍需单独验证。
