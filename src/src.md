# src 速查

## 职责

Vue 3 渲染进程入口，负责页面编排、播放状态及交互；系统能力通过 preload 白名单使用。

## 直接子目录

- `api/`：本地酷狗 HTTP API 与认证信息封装。
- `assets/`：随渲染构建导入的静态资源。
- `components/`：通用、布局和播放器组件。
- `stores/`：响应式设置与播放会话状态。
- `styles/`：全局主题变量、reset 和复用样式。
- `themes/`：内置和可分享主题包、共享校验与制作格式。
- `utils/`：日志、主题、对象操作及菜单管理。
- `views/`：页面组件及页面私有逻辑、样式。

## 直接文件

- `main.js`：并行初始化设置并等待本地 API 就绪，再创建 Vue 应用并挂载到 `#app`；首个动画帧通知主进程显示窗口，浏览器预览兼容无桥接。
- `App.vue`：登录、页面导航、播放队列、会话恢复、快捷键、自动歌词显示及跨页面外观编辑编排；首页与播放器同步载入，其余页面和外观编辑器首次打开时按需加载。
- `App.css`：根布局私有 scoped 样式，由 App.vue 外置引用，不进入全局样式入口。

## 核心流程与保障

- 页面发出播放事件，App 保存队列和目标歌曲，播放器完成加载后回写实际歌曲；播放全部一次发布完整队列，不用微任务分批追加，避免旧批次污染后续选歌及反复渲染。
- App 向收藏、搜索、每日、排行、专辑、歌手与 FM 传递同一 currentSong，页面据此标识当前曲目，不持有第二份播放状态。
- App 通过同一 hasPlayer 条件挂载播放器并设置页面根节点的底部空间；空队列释放空间，胶囊及窄窗口按布局增加间距。播放器移除时清理标题栏歌词状态。
- 播放栏自身在第一首歌曲成功播放后触发整栏入场，等待时隐藏空壳但保留音频挂载；App 的 player-slide Transition 负责移除时退场，动画样式维护在播放器目录。
- 队列变更由 App 响应 `playlist-updated`，子组件不直接修改父级队列。
- 设置和播放会话通过 settings store 保存，不建立第二套全局状态。
- App 同步恢复队列，并将绑定歌曲 hash 的 initialPlaybackState 交给播放器首次加载消费；确认或取消后清除，重新挂载不会重复恢复旧进度。恢复未完成或新队列尚无有效音源时不保存初始零值。
- 会话通过播放器 getPlaybackSnapshot 采集已确认歌曲，索引按该 hash 定位；替换音源使用替换前快照，父级待选目标不参与音源身份判断。每 5 秒检查点等待本次持久化后再计时；播放/暂停、跳转、音量、模式及歌曲确认即时保存，卸载清理定时器。
- 安装准备通知由 App 常驻订阅：暂时阻止界面输入，排空设置页草稿、保存最新会话并等待持久化队列。异步切歌、自然续播或系统媒体控制在保存期间改变会话时重新采样保存；只有当前请求仍有效才回执。失败或取消恢复输入，卸载解绑通知，迟到保存不能确认退出。
- 安装准备时若恢复偏好要求保存会话，但待播音源尚未确认，明确报告保存失败，不能把暂不可采样的空快照当作最终会话确认退出。
- 外观编辑器独立于缓存页面挂载到 body，设置页打开前先保存草稿；独立恢复入口使用 Shadow DOM 并排除主题覆盖，可在界面被自定义样式隐藏时恢复内置外观。
- 认证失效事件清理本地登录信息并切换登录页。
- App 持有侧边栏选中歌单 ID；登录页位于主内容区，浮栏持续显示，主页及设置导航可退出登录页。
- 主内容以短过渡切换直接页面组件，KeepAlive 最多保留 12 个主页、收藏、歌单、搜索和详情实例；按资源 ID/关键词区分。每页独立滚动，离场保存位置、重新激活恢复位置，隐藏页面不接受操作。
- 非首页页面使用异步组件拆分构建资源，保留实际页面名称、缓存 key 与 ref 透传；加载错误由统一 logger 保留原异常。设置和主题仍在应用挂载前完成初始化，避免默认页或配色闪回。
- 登录和设置不缓存，沿用二维码清理及设置保存生命周期。仅打开登录不清缓存；实际账号改变、退出或认证失效更换缓存代次，首次渲染前恢复账号以避免双重首页请求。
- 侧栏目录复用同一进行中请求并传入收藏页；收藏变化只标记首页 AI 推荐需刷新。普通歌单复用 FavoriteView，传入选中 ID 与名称。
- 全局快捷键串行更新；卸载时取消恢复等待、计时器与事件订阅。
- 聚焦按钮或链接时，Space/Enter 保留原生激活行为，避免歌词页收藏、翻译等操作被播放快捷键拦截。
- 日志通过统一 logger 脱敏，正常高频流程使用 Trace。
