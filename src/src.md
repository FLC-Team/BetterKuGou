# src 速查

## 职责

Vue 3 渲染进程入口，负责页面编排、播放状态及交互；系统能力通过 preload 白名单使用。

## 直接子目录

- `api/`：本地酷狗 HTTP API 与认证信息封装。
- `assets/`：随渲染构建导入的静态资源。
- `components/`：通用、布局和播放器组件。
- `stores/`：响应式设置与播放会话状态。
- `styles/`：全局主题变量、reset 和复用样式。
- `themes/`：内置和可分享主题包、共享校验与制作格式。
- `utils/`：日志、主题、对象操作及菜单管理。
- `views/`：页面组件及页面私有逻辑、样式。

## 直接文件

- `main.js`：初始化设置后创建 Vue 应用并挂载到 `#app`。
- `App.vue`：登录、页面导航、播放队列、会话恢复、快捷键和自动歌词显示编排。
- `App.css`：根布局私有 scoped 样式，由 App.vue 外置引用，不进入全局样式入口。

## 核心流程与保障

- 页面发出播放事件，App 保存队列和目标歌曲，播放器完成加载后回写实际歌曲。
- App 通过同一 hasPlayer 条件挂载播放器并设置页面根节点的底部空间；空队列释放空间，胶囊及窄窗口按布局增加间距。播放器移除时清理标题栏歌词状态。
- 队列变更由 App 响应 `playlist-updated`，子组件不直接修改父级队列。
- 设置和播放会话通过 settings store 保存，不建立第二套全局状态。
- 认证失效事件清理本地登录信息并切换登录页。
- App 持有侧边栏选中歌单 ID；登录页位于主内容区，浮栏持续显示，主页及设置导航可退出登录页。
- 主内容以短过渡切换直接页面组件，KeepAlive 最多保留 12 个主页、收藏、歌单、搜索和详情实例；按资源 ID/关键词区分。每页独立滚动，离场保存位置、重新激活恢复位置，隐藏页面不接受操作。
- 登录和设置不缓存，沿用二维码清理及设置保存生命周期。仅打开登录不清缓存；实际账号改变、退出或认证失效更换缓存代次，首次渲染前恢复账号以避免双重首页请求。
- 侧栏目录复用同一进行中请求并传入收藏页；收藏变化只标记首页 AI 推荐需刷新。普通歌单复用 FavoriteView，传入选中 ID 与名称。
- 全局快捷键串行更新；卸载时取消恢复等待、计时器与事件订阅。
- 聚焦按钮或链接时，Space/Enter 保留原生激活行为，避免歌词页收藏、翻译等操作被播放快捷键拦截。
- 日志通过统一 logger 脱敏，正常高频流程使用 Trace。
