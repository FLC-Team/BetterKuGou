# assets 速查

## 职责

维护由 Vite 随渲染代码导入的静态资源。

## 直接子目录

- `icons/`：播放器、窗口控制及相关 SVG 图标。

## 文件与调用

本目录没有直接业务文件；图标通过 JS import 得到构建后的资源地址。
调用方位于布局、播放器和页面组件，避免写死构建产物路径。

## 关键保障

- 应用 Logo 由项目 public 维护，不在 assets 增加重复位图副本。
- SVG 图标沿现有图标风格与引用约定维护。
- 加载视觉使用共享 CSS spinner，不新增大体积加载 GIF。
- 增删资源需核对实际 import；生成文件不得混入源码资源目录。
