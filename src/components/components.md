# components 速查

## 职责

维护可复用界面组件，页面级功能进入 views。

## 直接子目录

- `common/`：跨页面通用交互组件。
- `layout/`：标题栏、侧边栏和用户菜单。
- `player/`：音频播放器、歌词与播放队列。

## 直接文件

- `index.js`：向 App 导出 TitleBar、Sidebar、MusicPlayer。

## 数据流与保障

- 根组件经公共出口导入顶层组件，组件内部相邻引用沿现有目录关系。
- props 提供外部状态，用户操作通过事件反馈给父级。
- 播放器完成音频加载后通知 App，播放队列更新也由父组件处理。
- 窗口与系统控制通过 preload API，不直接启用 Node 能力。
- 组件拥有的定时器、全局监听和订阅必须在卸载时释放。
- 复杂播放器按 Vue 模板、JS 逻辑、scoped CSS 拆分。
