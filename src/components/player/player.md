# player 速查

## 职责与子目录

管理音频、播放导航、歌词显示与队列交互。
- `styles/`：播放器及歌词视图的外置 scoped CSS。

## 直接文件

- `MusicPlayer.vue`：音频元素、控制栏、队列与歌词组件模板。
- `MusicPlayer.js`：歌曲/歌词加载、播放模式、索引、待播队列及系统媒体控制。
- `LyricView.vue`：封面、歌曲信息、歌词、翻译和原生进度控件模板。
- `LyricView.js`：共用 LRC/KRC 时间轴的秒单位映射、逐字高亮、按播放时间同步的歌词位移和跳转交互。
- `VolumeControl.vue`：两种底栏及全屏歌词共用音量控件；拖动、静音与右键/百分比数值输入只发事件，不持有独立播放状态。
- `PlaylistDrawer.vue`：过滤队列、当前曲目定位、双击播放和删除事件。
- 播放列表的会员标识复用公共 SongBadges，依据歌曲权限字段，独立于 SQ 音质标记与真实播放权限判定，不以标签宣称解锁。

## 核心流程

- `requestSong(song, transition)` 将最后一次选歌及来源一起保留，挂载或切歌结束后由 `drainPendingSong()` 顺序加载；加载中的导航被直接选歌取代时，动效也跟随最新请求。
- 歌曲详情、地址与 `play()`（含旧源恢复）等待通过 `waitForSongOperation()` 接入取消及 15 秒超时；新选歌立即抢占恢复等待，并通过独立 AbortController 取消旧详情/地址 HTTP 请求。停止/卸载同时取消请求、恢复等待及定时器，迟到结果不提交或复活已清空音源。
- 前后切歌在忙时由 `queueNavigation()` 从最新待选/加载目标继续定位并立即替换请求，保留优先队列与随机/自动来源；控件不因加载锁禁用。每次导航用已尝试 hash 集合立即跳过失败项，不设置固定重试延时；排队导航沿待播选项保留重试上下文，最多尝试五首，最终保留旧歌时同步父级歌曲与索引；停止代次使旧重试循环立即结束。旧源自然结束不跳过已经请求的新歌曲。
- `loadSong()` 取得播放地址并成功播放后，提交 currentSong/loadedSongHash/trackTransition、按 hash 同步索引并发出 song-changed；同首重播也经过加载锁和请求代次检查。
- 音源先等待当前账号缓存会话并查询精确音质，命中时跳过在线详情和地址；未命中继续在线，详情、地址或 CDN 播放发生明确网络错误才允许使用该账号其他已缓存音质，权限、认证、取消及解码错误不降级。已确认在线音源后续触发媒体网络错误时保留位置、播放意图、歌词和动效换成本地源，不重取在线地址。实际音质仍由缓存保存的格式与码率确认，不把偏好当成有效音质。
- 本地音源通过不透明地址与租约播放；待播、当前和回滚音源在切换期间均受保护，成功换源后才释放旧租约，取消的迟到查询立即归还租约，停止和卸载清理全部租约。音频只在已确认音源真正播放后调用缓存队列，不预取整单，暂停恢复必须等待实际播放才缓存。
- `initialPlaybackState` 仅由首次匹配 songHash 的选歌消费；loadSong 等待音频可播放，先恢复音量、模式与进度，再按 isPlaying 决定播放或保持暂停。暂停恢复同样正式确认歌曲与音源；新选歌、停止和卸载取消旧恢复等待，不将旧进度套到新歌。
- `getPlaybackSnapshot()` 仅返回 loadedSongHash 与 currentSong 一致的歌曲及有效时间；替换音源前保留 replacingPlaybackSnapshot，临时音源零值或未提交歌曲不进入会话。原生 seeked 统一发出 playback-state-changed，覆盖进度条、歌词及系统媒体跳转。
- 替换音源前保存已提交歌曲的最新播放位置、时长与暂停状态；播放失败或请求被新选歌取代时，先恢复该音源身份与位置，恢复播放等待可被最新请求立即抢占。恢复未完成时跨请求保留确认快照，恢复成功后立即回到实时采样，避免后继失败撤销用户暂停或倒退进度；停止/卸载清空快照并通过独立音源代次拒绝迟到恢复。安装候选源时先清零默认起播位置，再按启动恢复或换质需要定位，防止快速换源继承旧 seek。
- 底栏与全屏歌词共用音质偏好入口，`playback.quality` 持久化 128/320/flac/high，后续歌曲继承。换质沿 pendingSongOptions/loadingSongOptions 保留目标歌曲、过渡、启动恢复位置/暂停状态及导航失败续跳上下文；当前歌等新音源可播放后恢复替换前最新位置与暂停状态，不重置歌词、队列或歌曲动效。
- 全屏歌词以紧凑胶囊打开音质菜单，勾选只代表偏好，菜单另示实际音质或切换状态；同档也可重选。已加载缓存档位的显式重选会尝试在线音源，网络失败仍可回到缓存；切换其他档位保持精确缓存优先。菜单支持方向键、Home/End、Escape、焦点移出和外部点击关闭，与右键菜单共用管理器保持互斥。
- 实际音质读取已提交响应的 extname/bitrate（兼容 extName/bitRate），缺格式时从实际选用的首条播放地址路径扩展名确认；仅格式可知时只显示格式，不猜码率，完全缺失时明确提示音源未提供信息；所选偏好不作为无损凭据。权限、地址、解码或播放失败保留旧音源与旧有效音质，并显示可重试的反馈；偏好保存失败保留尝试值用于重试。停止/卸载与新请求取消 canplay 等待并清理监听和定时器，换源期间暂停进度提交，时间事件/RAF/系统媒体和桌面歌词保留已提交位置，避免临时源的零时间回传。
- 最终选歌失败且父级仍指向该失败项时，通过 song-changed 回写实际保留的歌曲；有更新待选项时不回写。保留歌曲的未完成歌词被请求失效后，仅在歌词仍空且没有更新选歌时重新加载。
- 底栏通过 barSong 依次预览 pendingSong、loadingSongTarget、currentSong 或首次失败歌曲，首个请求即添加 player-ready；封面加载指示及文字显示取址/缓冲/恢复阶段。不同待播歌曲的时间为占位，收藏、歌词和进度操作暂不可用，前后导航仍可抢占；播放/暂停沿用已确认音源。App 保留清空队列时的退场，切歌不重复整栏入场。
- songLoadError 在底栏上方显示失败歌曲与原因并提供重试，失败回到已确认歌曲，首曲失败保留可见预览。重试保留请求音质和启动恢复位置/暂停意图，不延续旧导航跳过上下文；新请求、成功及停止清理反馈。歌曲错误优先于音质错误显示，关闭或重试后恢复音质反馈，避免两条浮层重叠。
- 底栏封面、歌名、歌手分别随 barSong 的 hash 使用 Vue Transition，预览动效读取最新请求来源，不修改已确认 trackTransition；上一首 previous 与下一首 next 反向横移，直接选歌 select 上移，随机下一首 shuffle 缩放，自然播完 auto 淡入。待播队列手动续播和删除当前曲目后的替补使用 next；上一首在随机模式仍保留后退方向，自动续播始终使用 auto。
- 首次挂载、同首重播和单曲循环不触发信息替换动画；歌词页、快捷键、系统媒体和托盘复用导航入口。封面按钮复用 ArtworkCover 并立即加载图片，缺图或失败保持占位，支持键盘打开歌词。
- 歌曲及歌词分别使用请求代次，过期响应和卸载后的响应不写回状态。
- 歌词库启用时先读所选版本；后台在线更新只在请求、歌曲、账号代次仍有效时保存，更新后仅刷新自动选中的新版本。编辑和选择通知忽略 hash 大小写，刷新不再次触发后台更新；关闭管理重新走缓存/在线路径，不删除库。
- 无库记录的历史缓存歌词先显示，再在线核实来源后按最低匹配自动保存；手动库版本不写回账号离线缓存，避免关闭管理后仍读到编辑内容。保存失败不阻断显示。
- currentLyrics/currentLyricData 保持原始数据，displayLyric 与桌面解析各自生成显示副本。简繁、分词、脏词设置实时重算；来源日语罗马音独立于翻译开关，全屏作为附加行，桌面和可见译文组合于副行。全屏与桌面解析统一处理 offset、多时间标签及源行翻译，保留逐字时间和原文空格。
- playPrevious 仅在 `playback.restartOnPreviousNearEnd` 开启、稳定且无待播请求时，用已确认音源实际剩余 0–10 秒判断原地重播，复用 loadSong 的同首路径及取消保护；暂停时主动播放，不重取音源或改变顺序/动效，原生 seeked 与最终状态通知保持会话同步。开关默认关闭，点击时读取最新设置；关闭、未知时长及忙时导航保持原行为，短曲沿用相同剩余时间规则。
- handleEnded 只处理真实 ended 且不在 seeking 中的音频，防止重播或跳转后迟到的旧事件触发续播；加载新目标期间继续保留已请求的选歌意图。
- 播放栏、歌词和抽屉发出 search(song)，MusicPlayer 收起覆盖层后向 App 转发；歌曲标题退场层禁用交互，队列序号/播放指示区提供原生播放按钮。
- 三处歌手均复用 ArtistLinks，逐人发出选中信息；MusicPlayer 的 openArtist 取消待打开歌词、收起歌词与队列后发出 navigate('artist', { id, name })，不更换音源或队列。底栏固定高度区域横向滚动，歌手退场层沿用标题的 inert/aria-hidden 保护。
- 删除或新增队列发出 playlist-updated，由 App 替换父级播放列表。
- 歌词通过播放器传给 LyricView；桌面格式由 `utils/desktopLyrics.js` 的 `parseDesktopLyrics()` 纯解析器生成，保留源空格、Unicode、KRC 逐字时序、LRC 多时间标签与偏移，以及原始响应的 UTF-8 翻译。
- `syncDesktopTrack()` 仅发布已确认音源的 hash 身份与规范歌名/歌手，歌词和时间消息带同一身份供主进程拒绝迟到数据；同名不同曲仍能正确清空。`clearDesktopPlayback()` 在停止/卸载时发布 null，避免重开桌面窗口复现旧歌。
- `syncDesktopTime()` 沿实际音频位置发送毫秒时间与总时长；连续播放保留 150ms 节流，附带真实音源的可推进状态、倍率与跳转标记；桌面在权威时间锚点间仅做最多 300ms 的视觉插值，缓冲和换源期间冻结。歌词到达、暂停/恢复、跳转、seeked、首次恢复及同首重播强制发送最终位置。待确认/换质/回滚源不覆盖有效桌面进度；显示和控制共用原主播放器状态，不增第二份播放时钟。
- 全屏歌词真正进入时通过 `electronAPI.setLyricViewVisible(true)` 通知主进程；退出动画完成或播放器卸载才释放桌面隐藏状态。快速重开忽略旧退出回调，主进程结合可见性与显示器决定是否隐藏桌面歌词。
- 歌词优先读取当前账号磁盘缓存，缺失或缓存读取失败才走原在线流程；在线真实歌词完整响应（含翻译）只在当前歌曲已经实际播放后持久化，暂停恢复期间不写入。缓存失败不阻断音频或原歌词显示，账号代次与歌曲请求代次共同拒绝迟到结果。
- MusicPlayer 的 isLyricPlaceholder 标记加载/服务提示与默认歌词，真实响应才允许 LyricView 的 lyricsInteractive；解析失败的“暂无歌词”同样不可操作。
- 全屏歌词的封面、标题、歌手和歌词按 trackTransition 采用前后反向横移、选歌上移、自动续播轻移或随机缩放，标题/歌手/歌词依次延后 45/90/110ms；背景按封面 URL 交叉淡化，首次挂载与同首重播不触发替换动画。
- 全屏背景和唱片封面使用 ArtworkCover 的 imageOnly 模式，命中本账号封面缓存时直接显示本地图片，保留原生 img 及过渡类；真实图片加载后才缓存，换源和退场卸载释放租约，原始地址与 trackKey 共同隔离旧层错误。
- 歌词层以歌曲 hash 和 loading/ready 阶段区分；加载时显示提示，响应到达后从当前播放时间入场，不继承旧桥段、高亮或长句位置。退场层 inert 且 aria-hidden，行引用按阶段及元素身份隔离，旧封面错误不得影响新层。
- 全屏歌词与播放列表 Teleport 到 body，避免播放器的动画或胶囊背景改变固定定位；歌词从窗口底部滑入并覆盖标题栏背景，窗口操作保留在透明标题栏上。
- 关闭歌词先使待显示请求失效，退场完成后才通知 App 复原标题栏；快速重开及卸载后的旧回调不回退状态，队列清空由 App 清理显示状态。
- 右侧播放列表整栏向右收起，保留贴边展开图标及原播放器入口；隐藏内容 inert，展开聚焦关闭按钮，Escape 收起后恢复焦点。
- 播放抽屉由整壳 Vue Transition 承接进退场，关闭时曲目与外壳一起滑出，完成后释放全量曲目 DOM；初始隐藏不创建列表，快速重开取消旧退场。遮罩与贴边恢复按钮双向过渡，退场层立即 inert/aria-hidden，重开清除旧属性；打开后的当前歌滚动沿用 nextTick 定位。
- 歌词页与两种播放器布局的进度条在拖动 input 时立即更新预览时间、歌词位移、逐字高亮与桥段；松开后只提交一次音频 seek，非法时间不写入音频。
- MusicPlayer 保留真实 currentTime，使用独立 seekPreviewTime 驱动滑块、时间标签及 LyricView 的 previewTime；歌词本地预览优先，其次为父级预览，最后才是真实时间，真实 timeupdate 与 RAF 不覆盖拖动位置。
- Escape、pointercancel、blur 取消预览并回到最新实际播放位置；切歌、停止、关闭及卸载也清理预览，没有待提交预览时忽略迟到的 change。
- 正常换行使用 0.45 秒纵向过渡；进度预览、提交及前后跳转立即同步高亮、横向位移和桥段，纵向使用 0.24 秒过渡跟随最新目标，首次定位不从首句滚入。
- 桥段中心由三组光点展开成 21 点流动波形，最后至多 2.4 秒收拢，并显示前奏/间奏与整秒倒计时。现有歌词 RAF 通过播放器只读 `getAnimationPlaybackTime()` 采样音频位置，只直接更新当前行逐字填充/横移及桥段粒子、光晕和配色；公共进度与整页歌词仍沿用原节流，不因桥段逐帧重建歌词节点。换源、回滚或无有效音频时使用保留的公共时间，本地/父级预览优先，暂停冻结，预览取消回到音频位置。
- 桥段 DOM 缓存不进入响应式状态，Vue 负责布局、显隐、倒计时和静态点，不绑定逐帧粒子样式；入场先初始化，切歌、停循环及卸载释放引用。系统减少动态效果时跳过隐藏波形的计算和写入，保留三枚进度点及倒计时；动态切换偏好后下个现有 RAF 即生效。实例按歌曲内容与桥段区间隔离，外层定位保持独立浏览锚点。
- 桥段前句仍显示在其上方，前奏首句保持在下方；屏外行保留夹紧后的定位以承接远距离跳转，末句 LRC 使用歌曲总时长计算高亮。桥段配色连续插值既有主题令牌，再与歌词颜色混合。
- 外层歌词行负责纵向定位，内层文本按播放时间与溢出宽度计算横向位移；暂停、跳转和 resize 不依赖独立 CSS 动画计时。
- 拖动/滚轮只更新独立 browsePosition，不替代真实时间、播放索引或逐字高亮；6px 阈值区分单击与拖动，5 秒闲置或回当前按钮恢复跟随，拖动/菜单期间不计时。真实歌词支持点击、Enter/Space 跳转句首，保留暂停状态；键盘聚焦歌词时固定浏览位置。
- 右键复用 ContextMenu 和菜单管理器，打开时快照本句/翻译/全部原文，复制不读取 DOM 中的零宽占位；优先固定 Electron 写桥接，网页使用 navigator.clipboard，异步失败可见。切歌、歌词替换、关闭、失焦、取消及卸载释放指针、监听、菜单及计时器。
- 全屏逐字使用 CSS 主题色的左右填充边界，字重和字形位置保持稳定；KRC 词内按 Unicode 字素分配时序，保留空格、组合字符和 emoji，普通 LRC 按下一句或歌曲末尾均分字素时间。
- 全屏现有 RAF 通过只读音频采样推进当前字填充与长句横移，不逐帧写响应式时间；行索引、桥段和纵向过渡共同随公共时间更新，进度预览始终优先。WeakMap 缓存当前行字节点与尺寸，ResizeObserver 仅在内容/字体/视口变化后重测；同一歌曲异步歌词替换在 Vue 更新后重新缓存，停止、切歌和卸载释放观察器。

- 两种底栏与全屏的播放/暂停及播放模式图标在固定网格内按状态切换；音量固定同一个喇叭主体，只让声波与静音标记过渡，快速跨档可直接反转，不叠放整张图标。音量填充与原生滑块共用有效行程，拖动即时更新；静音保留原位置并降低填充亮度。原生按钮保留按压和键盘反馈，不新增播放状态或延迟业务事件。
- 底栏音质复用 AnimatedSelect，展开、活动选项和值替换均有动画；只将偏好传给原有 changeQuality，同档可重选重试，菜单状态区继续区分实际音质与保存偏好。
- 全屏音质菜单、音质/翻译失败条、回当前按钮与复制状态有独立进退场；菜单和交互反馈的旧层立即退出焦点与辅助技术访问，重开恢复。音质切换中提供可见忙碌状态与禁用重试，沿用原事务。
- 翻译通过保留同一歌词行及翻译 DOM 的网格高度折叠显隐，行定位沿原播放/浏览状态过渡，不重新解析歌词或替换行引用。所有新增动效遵循减少动态效果。

## 关键保障

- loop/single/shuffle 模式沿用现有行为，同首已结束音频允许重新播放；同 hash 仅在有效音源和 loadedSongHash 一致时跳过外部重复选歌。
- 删除歌曲同步清理下一首队列；删除末首或清空时停止音源并使加载失效。
- 静音显示与 audio.muted 保持一致，音量限定为 0–100。
- MusicPlayer 的 handleVolumeChange 接收两处控件及本地/全局快捷键的数值，统一写入 audio.volume、静音状态、LocalStorage 并通知会话保存；0% 后取消静音恢复本次最后非零音量。输入框只在确认 0–100 整数后提交，空值和非法值保留草稿及错误提示，Escape/取消/外部点击不提交。
- 音量输入层 Teleport 到 body 并限制在视口内，与现有菜单管理器互斥；打开聚焦并选中数值，确认/取消恢复入口焦点，歌词显隐、失焦、缩放和卸载关闭并释放监听。退场立即不可交互，快速重开恢复交互，减少动态效果下立即切换。
- 卸载清理 RAF、等待定时器、托盘订阅、MediaSession 和菜单回调。
- 歌词视图挂载启动 RAF 并移入键盘焦点；卸载取消 RAF 与 resize 防抖，恢复原滚动状态及仍有效的先前焦点。
- 连续跳转直接更新当前过渡目标，不再使用延迟恢复过渡的回调；翻译 language 的 Base64 以 UTF-8 解码，只有实际映射到非空译文才显示开关。翻译持久化只提交开关字段，保存期间与失败后保留最新显示意图，失败提供可见重试，旧请求不能回退后续操作。
- 播放器读取本地收藏状态时检查备份账号归属，避免跨账号显示旧收藏。
