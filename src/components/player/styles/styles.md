# player/styles 速查

## 职责

播放器与歌词界面的私有 CSS，由对应 SFC 使用 scoped style src 导入。
本目录没有子目录。

## 直接文件

- `MusicPlayer.css`：播放器控制栏、默认底栏与 netease 悬浮胶囊布局、底栏歌曲信息过渡、进度、音量和全屏歌词纵向进退动画。
- `LyricView.css`：双栏封面布局、普通进度条、简洁播放控件、逐字状态、翻译、全屏切歌内容层过渡和背景交叉淡化。

## 设计与保障

- 底栏音质使用 `:deep(.quality-select)` 约束通用选择器宽度，弹层由公共组件独立定位，不再使用原生 select 的局部样式。
- 音量图形通过稳定 SVG 节点的 opacity/transform 过渡，轨道填充直接跟随值，避免拖动延迟；父级只在控件根传递宽度与显隐变量，不能用父 scoped 选择器控制内部滑条。
- 组件行为位于上级 JS，CSS 只维护布局、视觉状态和动效。
- 颜色、渐变、图标 filter、阴影和圆角复用主题包全局变量，间距与字体沿用全局规范，避免独立复制主题来源。
- 歌词视图使用 `--lyric-*` 专用变量，保持封面背景上的文字、控件与逐字高亮配色协调；歌词 JS 的直接 DOM 样式使用同组变量。
- 播放模式和歌词开关的选择器与实际模板 class 保持一致。播放/静音/模式图标的 control-state 只过渡固定网格内的字形，不占用切歌层或歌词行 transform；按钮用独立 scale 提供按压反馈。
- 同时考虑小窗口、全屏歌词以及两种播放器布局。
- VolumeControl 的控件、输入层及状态动画维护在组件 scoped 样式内；MusicPlayer.css 通过音量宽度/显隐变量适配底栏，窄窗只隐藏滑条，保留静音和数值按钮。歌词工具区可换行，音量图标继承歌词主题文字颜色；输入层独立挂到 body，不受胶囊或歌词布局裁切。
- 音质选择沿用主题变量，底栏显示实际音质，错误在栏上方提供可读提示与重试。全屏歌词的音质胶囊与纯文字翻译开关并排，菜单分列名称与格式/码率、独立显示实际音质；宽窗向上展开，窄于 700px 时向下展开，实际测量后夹紧视口边界，受限高度内可滚动。常态收起状态说明，错误时提供反馈及重试。窄窗口工具随播放面板布局，不固定到标题区域；两种底栏在小于等于 600px 时将播放控制放到第二行。
- 整栏入场由首个选歌预览的 player-ready 触发；封面遮罩与旋转环、歌手下方加载状态提供即时反馈，减少动态时保留静态环及文字。不同待播歌曲的进度/收藏/封面禁用态保持可辨；player-slide-leave-active 后置以覆盖入场并保留退场。纵向位移包含胶囊底部间距，减少动态效果时禁用两者。
- 底栏 song-meta 过渡读取 song-info-section 的 data-motion，使用 transform/opacity 表达前后导航、上移选歌、随机缩放及自动淡入；标题与歌手分别延后 35/70ms，离场层绝对定位，固定封面及文本视口避免布局跳动。
- 底栏歌手视口保持 18px，高度内由 ArtistLinks compact 模式提供横向滚动；歌词歌手与队列允许换行，避免截断后续歌手入口。按钮颜色继承各自区域的主题变量。
- 封面按钮在窄窗保持固定正方形，焦点描边内收以兼容胶囊裁切；系统减少动态效果时禁用歌曲信息位移及过渡，清理交由 Vue 生命周期完成，不使用额外计时器。
- netease 沿用设置值，胶囊距底 20px、宽 90%、最大 1200px、高 80px、圆角 15px；三栏可收缩，窄窗口将控制与进度放在下行，配色仍来自主题包。
- 歌词根层覆盖整个视口，内容区单独避让标题栏；只过渡纵向位移，退场不缩放或淡出，并尊重减少动态效果设置。
- 全屏切歌使用独立 track-piece 内容层的 transform/opacity，不覆盖歌词行定位；封面与文字采用网格重叠，歌词采用定位重叠，退场不挤压布局。前后导航、选歌、自动续播和随机播放使用各自方向或缩放，封面背景以 0.8 秒交叉淡化，减少动态效果时均立即替换。
- 全屏逐字与桌面采用同样的左右填亮样式，`--fill-progress` 控制当前字背景渐变边界；保持固定字重与位置，原始空格通过 white-space 保留。修改高亮或滚动样式时核对歌词逻辑中的直接 DOM 更新。
- 封面尺寸变量以实际视口独立计算，不自引用；矮窗口保留双栏并缩小封面，宽度小于 700px 时采用紧凑上下布局。
- 外层歌词定位与内层文本横移分开，进度滑块不被轨道裁切；按钮有键盘焦点样式，并尊重减少动态效果设置。
- 歌词桥段保留上一句及下一句可见；bridge-indicator 外层随浏览定位，内部光点用 transform/opacity 呈现展开、波形流动和收拢，进退场轻移并淡化。高度随行距夹紧，仅波形缩放，倒计时保持可读字号；复用歌词及桥段主题色，pointer-events 不阻挡歌词交互。减少动态效果时隐藏波形、禁用进退场位移和过渡，以三枚静态进度点及倒计时显示状态。
- 远处歌词用 visibility 和夹紧屏外位移隐藏，保留进度跳转时可插值的纵向起点。行距统一计算，避免逐行重复扫描翻译。
- 拖动期间位移目标随预览时间实时更新，音频时间回传不覆盖当前目标；取消后平滑返回实际播放位置。
- 音质菜单用透明度与独立 scale 进退，保留其既有 transform/translate 视口夹紧；chevron、选项勾选及忙碌指示同步过渡。工具提示和复制结果使用独立 translate/opacity，翻译通过 grid-template-rows 折叠，保留同一歌词 DOM；减少动态效果立即切换。
- 手动浏览歌词使用独立位置，开启可见行的鼠标/键盘操作；拖动时显示抓取光标并避免原生选择，回当前按钮与复制反馈使用歌词主题变量，桥段指示随对应浏览位置移动。歌名搜索按钮继承原排版并提供焦点样式，退场层不接受交互。

## 运行

- 罗马音使用歌词副文字颜色与小字号，当前歌词行按注释增加间距；入场有轻微透明度和位移过渡，减少动态效果时直接显示。
