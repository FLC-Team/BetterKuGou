# player/styles 速查

## 职责

播放器与歌词界面的私有 CSS，由对应 SFC 使用 scoped style src 导入。
本目录没有子目录。

## 直接文件

- `MusicPlayer.css`：播放器控制栏、默认底栏与 netease 悬浮胶囊布局、进度、音量和全屏歌词纵向进退动画。
- `LyricView.css`：双栏封面布局、普通进度条、简洁播放控件、逐字状态、翻译和歌词过渡。

## 设计与保障

- 组件行为位于上级 JS，CSS 只维护布局、视觉状态和动效。
- 颜色、渐变、图标 filter、阴影和圆角复用主题包全局变量，间距与字体沿用全局规范，避免独立复制主题来源。
- 歌词视图使用 `--lyric-*` 专用变量，保持封面背景上的文字、控件与逐字高亮配色协调；歌词 JS 的直接 DOM 样式使用同组变量。
- 播放模式和歌词开关的选择器与实际模板 class 保持一致。
- 同时考虑小窗口、全屏歌词以及两种播放器布局。
- netease 沿用设置值，胶囊距底 20px、宽 90%、最大 1200px、高 80px、圆角 15px；三栏可收缩，窄窗口将控制与进度放在下行，配色仍来自主题包。
- 歌词根层覆盖整个视口，内容区单独避让标题栏；只过渡纵向位移，退场不缩放或淡出，并尊重减少动态效果设置。
- 修改逐字高亮或滚动样式时核对歌词逻辑中的直接 DOM 样式更新。
- 封面尺寸变量以实际视口独立计算，不自引用；矮窗口保留双栏并缩小封面，宽度小于 700px 时采用紧凑上下布局。
- 外层歌词定位与内层文本横移分开，进度滑块不被轨道裁切；按钮有键盘焦点样式，并尊重减少动态效果设置。
- 歌词桥段保留上一句及下一句可见；远处歌词用 visibility 和夹紧屏外位移隐藏，保留进度跳转时可插值的纵向起点。行距统一计算，避免逐行重复扫描翻译。
