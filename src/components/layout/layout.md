# layout 速查

## 职责

提供应用外壳布局和窗口交互；本目录没有子目录。

## 直接文件

- `TitleBar.vue`：搜索、用户入口、窗口最小化/最大化/关闭及歌词状态布局。
- `Sidebar.vue`：浮动侧边导航、歌单滚动与选中指示条、账号菜单及登录/设置入口。
- `Sidebar.css`：侧边栏私有布局、展开动画、主题变量和矮窗口适配。
- `UserMenu.vue`：用户设置、资料与退出登录操作。

## 数据与调用

- App 提供 userLoggedIn、userInfo、当前页面和歌词显示状态。
- TitleBar 的窗口操作经 electronAPI，最大化状态由主进程事件同步。
- 标题栏采用三列网格，搜索居中且可收缩；Logo 与窗口操作只占各自内容宽度，其余标题栏留白保持可拖动。窄窗口隐藏用户名和品牌文字，避免挤压输入区。
- 搜索使用主题变量驱动的轻填充胶囊、前置提交图标和输入后显示的清空按钮；原生表单将规范化关键词交给 App，中文输入法选词期间不提交，Escape 仅在非组合输入时失焦。清空后继续聚焦输入框，按钮提供可见键盘焦点并适配减少动态效果。
- 歌词进场时标题栏立即透明，使歌词背景铺到窗口顶部；透明状态保持至歌词离场完成，搜索框随后恢复。
- TitleBar 通过 modelValue/update:modelValue 与 App 同步搜索草稿，search 事件只提交规范化关键词；输入草稿和清空不会改变当前搜索页，点击歌名提交后回填输入框。
- Sidebar 接收当前页面、selectedPlaylistId、歌单及用户信息；发出 navigate/create-playlist/show-login/open-settings/logout 事件，收藏未登录时进入登录页。
- 浮栏宽度从 60px 展开到 180px，悬停 300ms 后显示文字；主内容只预留窄栏空间，展开覆盖页面边缘。键盘焦点进入时立即展开。
- 收起按钮将整条浮栏滑出左边并释放主内容预留空间，仅保留贴边展开按钮；隐藏导航设置 inert 与 aria-hidden，不再响应悬停。展开后保留原导航/歌单状态并将焦点交还当前项；Escape 只收起文字和账号菜单。
- 顶部导航和底部账号/设置固定，中间歌单独立滚动；右侧唯一指示条跟随选中项，滚出可视区时隐藏。
- 账号使用用户头像或公共 Logo；登录后复用 UserMenu，菜单贴靠展开后的浮栏，底边避开播放器，Escape 或焦点离开可关闭。
- UserMenu 根据传入位置展示菜单，操作通过事件交回父级。

## 关键保障

- TitleBar 保存订阅取消函数，并在卸载时取消窗口状态监听。
- UserMenu 延迟注册点击监听，关闭和卸载都取消定时器及 document 监听。
- 延迟菜单回调检查 visible 与卸载状态，避免销毁后重新注册监听。
- Sidebar 卸载时清除悬停定时器、布局动画帧和 resize 监听，布局回调检查卸载状态。
- 隐藏时焦点转交展开按钮，恢复时回到导航项；减少动态效果偏好会禁用浮栏位移、空间和文字动画。
- 侧栏颜色、圆角、阴影及标题栏图标 filter 由主题包变量提供；侧栏 SVG 通过 CSS mask 继承状态颜色，小窗口保留歌单滚动区和底部操作。
- 窗口图标复用 assets，用户信息和凭证不得进入日志。
