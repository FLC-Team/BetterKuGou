# logic 速查

## 职责

承载复杂页面的 Options API 脚本，供上级 SFC 的外置 script 使用。
本目录没有子目录。

## 直接文件

- `ArtistView.js`：歌手资料、热门曲目、分页歌曲、专辑、关注与封面补全。
- `FavoriteView.js`：定位“我喜欢”或指定歌单、缓存当前页结果、分页加载与局部刷新，以及右键和本地收藏操作。

## 核心流程

- Artist 按传入歌手信息加载详情，规整曲目字段，再按 hash 或专辑信息补全封面。
- Favorite 优先复用 App 传入的账号歌单目录；指定 playlistId 时直接取该歌单，无值时兼容名称与 ID 定位“我喜欢”。首次加载合并进行中请求，成功及空列表均缓存，手动刷新只重新取已知歌单曲目。
- 分页先汇总到临时数组，全部成功后整笔替换列表；刷新不清空可见行，失败保留上一次完整结果。账号、token、歌单或请求代次改变后丢弃旧响应。
- 本地收藏增删仅更新相关行和已有备份并发送 favorites-changed，不发云端写请求；普通歌单不显示收藏已选状态。备份只有 favorite_songs_userid 与当前账号相同才允许回退读取。
- 云端完整收藏提交后仅在歌曲标识改变时通知依赖页面，元数据或相同内容刷新不重复通知；本地编辑会使尚未返回的刷新失效。
- 页面向 App 发出播放和导航事件，音频加载由播放器执行。
- 右键菜单使用统一菜单管理器，菜单回调仅负责业务事件。

## 关键保障

- 保留歌手、歌曲和专辑接口中的多种历史字段兼容。
- 收藏歌单支持数字型 ID；认证失效时不回退使用过期收藏缓存。
- 请求错误提供上下文，封面补全失败不能被无声吞掉。
- 歌手分页失败记录异常并解除 loadingMore，允许后续触发重试。
- Artist 在 KeepAlive 失活时断开 Observer，激活按当前标签恢复；旧回调、隐藏页及已淘汰组件不得继续分页。
- 页面私有样式位于上级 styles，复杂脚本不混入共享组件目录。
