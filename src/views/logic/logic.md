# logic 速查

## 职责

承载复杂页面的 Options API 脚本，供上级 SFC 的外置 script 使用。
本目录没有子目录。

## 直接文件

- `ArtistView.js`：歌手资料、热门曲目、分页歌曲、专辑、关注与封面补全。
- `listMotion.js`：收藏列表局部指令，只采样 IntersectionObserver 记录的可见曲目；WAAPI 处理进入/移动与 inert 离场副本，滚动、连输、失活及卸载清理动画、克隆和观察器。
- `layoutMotion.js`：首页网格更新的容器高度插值、离场项坐标冻结与取消恢复，兼容连续展开/收起和减少动态效果。
- `FavoriteView.js`：定位“我喜欢”或指定歌单、读取/保存完整离线曲目快照、分页加载与局部刷新、本地搜索、已听缓存状态，以及右键和本地收藏操作。

## 核心流程

- Artist 按传入歌手信息加载详情，规整曲目字段，再按 hash 或专辑信息补全封面。
- Artist 的 loadInitial 合并初始化与显式重试，缺 ID 时按选中姓名精确查找；无匹配、资料缺失及请求失败提供可见反馈，不查询无效 ID，热门请求失败不阻断已有歌手的其他标签。
- Favorite 优先复用 App 传入的账号歌单目录；指定 playlistId 时直接取该歌单，无值时兼容名称与 ID 定位“我喜欢”。首次加载合并进行中请求，成功及空列表均缓存，手动刷新只重新取已知歌单曲目。
- 分页先汇总到临时数组，全部成功后整笔替换列表；刷新不清空可见行，失败保留上一次完整结果。账号、token、歌单或请求代次改变后丢弃旧响应。
- 曲目按总数加载全部分页；接口缩小首批实际页长时，后续页码与偏移使用实际页长，避免跳行。缺少总数字段时同样按首批实际页长校准偏移并持续读取，直到短页或空页；返回数量不足已知总数时按失败处理，保留旧完整列表。
- 无总数分页遇到内容完全相同的满页时终止并报告未前进，避免接口忽略页码造成无限请求；不同页内合法重复的曲目不去重，行顺序与索引保留。
- 搜索通过 songMetadata 兼容曲名/歌手/专辑字段，过滤已排序的展示副本，不修改 favoriteList 或行对象；播放全部和单曲自动入队继续消费全量原队列。每个缓存实例保存自己的查询，scope 变化清空。
- Favorite 的完整展示数组交给 WindowedList 管理可见 DOM，业务逻辑不消费窗口切片；激活/失活通过组件根元素恢复/暂停 listMotion，保留原筛选、排序和行进退场动画。
- 本地收藏增删仅更新相关行和已有备份并发送 favorites-changed，不发云端写请求；普通歌单不显示收藏已选状态。备份只有 favorite_songs_userid 与当前账号相同才允许回退读取。
- 云端完整收藏提交后仅在歌曲标识改变时通知依赖页面，元数据或相同内容刷新不重复通知；本地编辑会使尚未返回的刷新失效。
- 桌面首次打开歌单先读取当前账号的完整磁盘快照，再继续本次在线校验；快照携带真实歌单 ID，使“我喜欢”在目录不可用时仍可打开。完整且合法的空快照不被旧收藏备份覆盖。
- 全部分页成功和本地收藏编辑后仅发布 putPlaylist 元数据；打开、搜索、刷新、激活和暂停/继续缓存均不发起整单音频或歌词预取。音频与歌词缓存由实际播放触发，组件只展示已听缓存数、可离线曲目标记及已有任务控制。
- 磁盘快照保存失败提供独立重试保存入口；音频任务的暂停、继续、空间/网络/失败状态和重试通过现有主进程缓存服务处理，不修改播放队列。
- 已加载页面再次激活时只按真实 ID 读取快照以更新最近访问，不替换可见行、搜索或排序，不重取网络曲目；快照已淘汰时由页面已有完整列表重建，不解除暂停或清理抑制。
- 页面向 App 发出播放和导航事件，音频加载由播放器执行。
- 歌手与收藏的所有曲目歌手入口复用 ArtistLinks，将选中的独立 { id, name } 交给 App；Artist 曲目规整使用 getSongArtists 保留多歌手 ID，对象数组及历史文本由公共工具兼容。
- 右键菜单使用统一菜单管理器，菜单回调仅负责业务事件。
- 收藏右键搜索与全部曲目歌名按钮都发出 search(原歌曲对象)，不在页面脚本拼关键词；歌手热门与全部单曲沿同一事件出口，原播放、入队与筛选状态保持独立。

## 关键保障

- 保留歌手、歌曲和专辑接口中的多种历史字段兼容。
- 收藏歌单支持数字型 ID；认证失效时不回退使用过期收藏缓存。
- 请求错误提供上下文，封面补全失败不能被无声吞掉。
- 歌手单曲/专辑分页失败显示重试提示并解除 loading 状态；关注操作锁定单次请求，按实际响应提交状态并提供可见成功/失败反馈。
- Artist 在 KeepAlive 失活时断开 Observer，激活按当前标签恢复；旧回调、隐藏页及已淘汰组件不得继续分页。
- 页面私有样式位于上级 styles，复杂脚本不混入共享组件目录。
