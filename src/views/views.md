# views 速查

## 职责与子目录

维护页面级组件；App 通过本目录公共出口选择页面。
- `logic/`：Artist、Favorite 页面 Options API 业务逻辑。
- `styles/`：复杂页面外置 scoped CSS。

## 直接文件

- `index.js`：页面公共导出。
- `HomeView.vue`：音乐杂志式首页，每日推荐封面主视觉、私人 FM、精选歌曲与独立榜单区；引用外置 scoped 样式。
- `LoginView.vue`：手机、账号和二维码登录；请求按钮绑定 disabled/aria-busy 和可见 spinner，成功/失败通过动画反馈区呈现，成功沿原认证事件导航。
- `PageLoadingView.vue`：首次异步页面模块加载超过 120ms 后显示的可见等待状态；外观编辑器使用固定位置浮动提示，避免主页面外插入占位内容。
- `SearchView.vue`：搜索、分页、歌曲操作与播放事件。
- `FavoriteView.vue`：收藏与普通歌单共用的列表模板，引用独立逻辑与样式，支持当前歌单刷新及全量已加载曲目的本地搜索、匹配数量与清空。
- `ArtistView.vue`：歌手页模板，引用独立逻辑与样式。
- `AlbumDetailView.vue`：专辑信息、曲目和播放入口。
- `RankDetailView.vue`：排行详情和曲目播放，通过独立曲目接口完整分页加载 Top500 等榜单。
- `PersonalFMView.vue`：私人 FM 内容与播放。
- `DailyRecommendView.vue`：每日推荐与全部播放。
- `SettingsView.vue`：杂志式设置分组与导航、播放/歌词偏好、音质偏好、主题包与全量令牌编辑、桌面与灵动岛歌词、应用更新、导入导出及快捷键配置；排空保存后打开 App 常驻区域/CSS 编辑器，音乐下载预留项明确禁用。

## 数据流与保障

- 设置的音质、桌面歌词大小/样式和启动页均用 AnimatedSelect 编辑原有 localSettings 草稿；更新渠道/安装包、缓存容量和主题区域沿各组件原事件保存，不增加第二份设置状态。选择器离焦仍触发原有保存排空。
- 页面调用 api 封装，规整歌曲字段后发出 play/play-all/play-next/navigate 等事件。
- 所有歌曲歌手及专辑头部复用 ArtistLinks，逐位发出 navigate('artist', { id, name })；结构化歌手信息优先，点击与双击不触发行播放。搜索播放/入队以及歌手、专辑曲目规整经 getSongArtists 保留各歌手对应 ID，不再合成一个可点击姓名。
- 所有单曲歌名按钮发出 search(原歌曲对象)，App 统一生成只含歌名的关键词；歌名阻止 click/dblclick 冒泡，行其他区域双击与行内播放按钮维持播放。Home/FM 封面播放与歌名搜索是同级按钮，专辑序号是独立播放按钮；专辑卡和栏目名继续原导航。
- App 持有导航、登录与播放队列，页面不自行创建音频播放器。
- Home、Favorite、Artist、Album、Rank、Search、Daily 由 App 按资源缓存；页面往返复用数据、排序及滚动位置，真实登录会话变化时释放。登录、设置和动态私人 FM 不缓存。
- Home 收藏变更只刷新 AI 推荐；每日推荐在跨本地日激活时刷新，首次 mounted/activated 不重复取数，模块请求合并并拒绝旧账号或卸载结果。
- 首页激活仅补拉失败或过期模块，成功空结果同样缓存；AI 按实际前十首收藏 hash 去重，尾部及元数据变化不重拉，显式刷新仍可更新相同种子。
- 首页封面复用每日推荐响应，不新增推荐接口请求；每日、精选与榜单图片经 ArtworkCover 的 imageOnly 模式先查本地封面，保留原生 img 布局和 eager/lazy 行为，仅真实图片加载后缓存。图片缺失或加载失败显示本地唱片排版，按实际尺寸隔离失败状态，资源刷新成功后允许重试。精选默认展示六首、榜单默认展示四项，均可展开全部；刷新保留已有推荐，首次加载显示骨架。原生按钮支持键盘操作，歌曲与歌手入口独立；根节点继续承担 App 的滚动缓存和播放器留白。
- 缓存页失活时关闭右键菜单，Artist 另外断开分页 Observer，激活后幂等恢复；不会让隐藏页继续触发分页。
- Artist 对无 ID 的单个姓名精确查找歌手，查无结果或加载失败显示可重试提示；失败时不以空 ID 发起详情或分页请求，热门失败仍允许已有歌手的其他标签加载。
- SettingsView 使用 settings store，临时编辑和主题预览不建立独立持久化来源；保存状态/结果、radio 选中、快捷键录制/清除/冲突和导入导出等待均提供动画反馈，快捷键提示计时器在卸载清理。
- “播放与歌词”的 playbackOptions 提供“歌曲即将结束时，上一首从头播放”开关，绑定默认关闭的 `playback.restartOnPreviousNearEnd`；沿现有草稿、防抖保存及失败重试流程持久化，说明明确最后 10 秒的触发范围。
- “播放与歌词”内的 LyricSettings 共用 playback 草稿及保存队列，承载歌词版本管理和内容处理；对外离页保存及整份设置导入前共用 prepareLeave，正文未保存或仍在读写时保留编辑并停止操作。导入等待期间歌词设置与管理区域 inert，防止新编辑被导入配置关闭；组件内部 beforeAction 只排空偏好保存，避免递归触发离页检查。
- SettingsView 在“启动与应用”挂载 AppUpdates，通过 v-model 编辑 `localSettings.software.updates` 并沿原流程保存；检查、下载和安装前先排空保存，失败不发起操作。侧栏版本由服务提供的实际应用版本更新，浏览器预览回退 package.json 构建版本并禁用桌面更新控件。
- 设置编辑分组与导航独立，包含 desktopLyrics/islandLyrics 但不包含 session。保存时忽略自身乐观广播，落盘后合并规范化值、外部分组变化与保存期间的后续编辑；失败保留草稿，可见的 sticky 错误条支持重试。离焦、离页和导入导出前排空防抖及进行中事务，导入导出失败会显示反馈。
- 桌面歌词由 `DesktopLyricSettings` 分组编辑 `localSettings.desktopLyrics`，包括显示/动效、隐藏规则、字体配色、阴影和窗口行为。“打开”及“找回并解锁”先排空设置草稿，共用等待状态防重入；打开等待窗口真实就绪，找回将窗口恢复到主屏下方并解除穿透。失败保留反馈与重试入口；桌面翻译音译隐藏只覆盖桌面显示，不改写全局偏好。
- 紧随桌面歌词的 `IslandLyricSettings` 通过 `localSettings.islandLyrics` 编辑完整偏好；模式、屏幕、左右内容和预设使用 AnimatedSelect，其余沿原 checkbox/range/color/text 交互及父级保存事务。大陆模式贴顶避让鼠标，浮动可拖动、顶部吸附，并通过点击或键盘展开控制；停用时仍可编辑偏好。
- 灵动岛“重新显示 / 找回”通过 beforeAction 排空草稿后调用窗口桥接，自动隐藏启用时预览 3 秒；等待防重入，失败可重试。屏幕热插拔优先于初始快照，拔出屏幕仍保留已保存选择；外部全屏检测按能力禁用，自家同屏全屏歌词隐藏跨平台可用。浏览器禁用系统窗口控件，局部翻译隐藏不改写全局偏好。
- SettingsView 通过 PlaylistCacheSettings 编辑 download 的离线缓存开关、容量和并发，管理动作前排空设置草稿。占用和目录只读，清理仅作用于当前账号，任务不依赖设置页存活；普通文件下载保持禁用，应用更新使用独立目录；不将内部播放会话作为偏好项。
- ThemePackages 通过 v-model 编辑 custom 分组；主题立即预览后沿用设置页保存流程，保存失败显示提示，会话广播后重放待保存的预览。
- 独立外观恢复先经 App 调用 `prepareThemeRecovery()`，暂停新保存并等待已有事务，只丢弃主题相关草稿及恢复期间的主题编辑；恢复写入成功/失败后按实际 store 解除握手，其余偏好草稿继续保存，防旧坏主题被防抖重新应用。
- LoginView 的计时器、轮询和过期请求在卸载时清理。
- 页面私有样式保持 scoped，高频调试信息使用 logger Trace。
- 各列表页面将加载、内容、空态和错误放在 ui-fade 过渡中；收藏仅观察视口内曲目以动画筛选、清空、排序和移除，保持全量原始队列。首页推荐/榜单用 ui-list 过渡及容器高度动画展开、收起与换批。
- 歌手标签使用移动下划线和内容过渡，进入完成后恢复分页观察器；关注请求防重入并显示等待和失败，单曲/专辑失败保留内容及重试入口，不旋转加载文字。
- 收藏/歌单、搜索、每日、排行、专辑和歌手曲目使用 scoped 列表样式，延续首页大封面、分区与留白；FM 以独立封面网格呈现。页面根保留滚动缓存和播放器留白，所有选歌、歌手/专辑导航、排序、FM 与歌手专辑卡都有原生按钮入口。
- 当前曲目只读取 App 传入的 currentSong 并标识高亮；行内按钮继续发出选歌事件，标签不宣称暂停。封面复用 ArtworkCover 的缺图/坏图回退，不新增 API 请求。
- 表头和曲目行共用时长/操作独立轨道，不同数量的操作按钮不挤动时长；歌手热门和全部曲目沿用同一布局，最窄窗口将操作移至时长下方，专辑无操作时仍居中对齐。
- 主要歌曲列表与首页/FM 推荐共享 SongBadges；VIP 标识与歌名截断区并列，读取原歌曲元数据，不影响选歌、导航或队列。
- 收藏/歌单检索覆盖全部已加载分页，按歌名、歌手或专辑忽略大小写匹配；只过滤展示，原始索引、右键对象及全量播放队列保持不变。查询随每个歌单缓存实例保存，刷新保留查询，账号或歌单 scope 改变时清空。
- 收藏/普通歌单通过 WindowedList 在超过 200 条展示结果时仅挂载可见区域及缓冲行；保留动态行高、键盘焦点和缓存滚动，行号与条纹使用全量展示索引。列表动效指令继续接收完整筛选结果，滚动换窗不触发歌曲增删动画。
- 专辑首次加载、失败和空结果均保留稳定页面根；搜索失败显示独立重试状态，迟到响应仍由原请求代次保护。Daily/Rank 刷新时保留已有曲目，失败显示局部重试提示。
- Rank 从 `/rank/audio` 的 `data.songlist` 每页读取 100 条，按返回总数加载完整榜单；无总数时读至空页，重复页或提前空页报告失败。完整成功后才替换列表，重复重试不并发请求，卸载后不提交迟到结果。嵌套音频 hash、专辑封面及名称规范化为现有歌曲字段，保留歌手 ID 与明确权限；列表 duration 使用秒，播放队列 timelen 使用毫秒。
