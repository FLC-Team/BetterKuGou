# utils 速查

## 职责

提供渲染进程共享工具；本目录没有子目录。

## 直接文件

- `logger.js`：日志级别过滤、统一脱敏、最多保留 500 条记录及主进程日志桥接。
- `themeManager.js`：主题包解析、旧 dark/light/system/custom 模式兼容、系统配色监听、完整 CSS 变量/限定作用域 CSS 应用、草稿预览取消及视觉快照导出。
- `objectUtils.js`：深拷贝、原地合并、响应式内容替换和可写副本。
- `audioEffectsEngine.js`：CORS 已授权的双 deck WebAudio 图，每个元素复用唯一 source；淡化位于插件前，主音量与静音位于插件后。通过限定连接握手把专用 MessagePort 直接转交 AudioWorklet，utility 进程重建后按连接代次重新握手而不重建媒体 source。输入 track/token 与延迟输出呈现身份分开；`getPresentedPlayback()` 返回实际可听曲目及位置，连续同源循环只添加标记、不重置 DSP 队列。显式 seek/效果启停携带呈现代次，拒绝同曲目的旧回执，暂停冻结旧输出时钟。保持媒体事务与播放队列由播放器持有；提供原始音频 BPM tap、自然结束尾音、跳转与停止清理，以及处理器异常后的原声回退。
- `contextMenuManager.js`：管理一个活动菜单关闭回调。
- `playbackQuality.js`：普通音质选项及菜单的名称/格式/短标签、偏好规范化及依据响应格式/码率（含驼峰历史字段）确认当前音源信息，缺少格式时读取实际首条播放地址路径扩展名；不读取查询参数/备用地址，不凭格式推断码率或以偏好推断实际无损。
- `playbackTransition.js`：供 MusicPlayer 双音频元素管理复用的取消/15秒超时等待、候选音源 canplay 就绪、线性且有界的音量增益包络及只读导航选择器；预览下一首不提前消费队列或修改随机顺序。
- `playlistCache.js`：可选桌面缓存桥接、串行账号初始化与等待、会话代次及跨账号迟到结果隔离；不持有第二份响应式缓存状态。
- `trailingSilence.js`：只对已完整缓存的当前歌曲进行独立尾部静音分析，不连接或改变正在播放的音频；返回 `silenceStart/skipAt/duration`，不可确认时返回 null。串行读取及原采样率解码受 64 MiB 文件、600 秒及 128 MiB PCM 上限保护，最多保留一个执行中和一个最新待执行身份；取消请求不提交迟到结果，原生解码结束并释放租约后才启动下一任务。32 条内存结果按会话、来源、音质及文件 SHA256 隔离，不持久化。
- `libraryMetadata.js`：在已知容器提取列表，保留歌曲权限、歌手、歌单 fileid 和云盘来源；将公开 globalCollectionId、用户 listId 与导航 id 分开。只信明确收藏标记，精确“我喜欢”名称仅标为待确认候选，不推断写入权限。
- 历史记录的 song/info 包装、mxid、audio_hash 与常见专辑封面字段统一为歌曲行元数据；原始文件名保留供云盘身份和显示层曲名解析使用。`normalizeLibraryArtist` 从关注列表的对象或 JSON 字符串 ext_params 读取 singerid/k_pic，统一 avatar 与 singername，不将用户 ID 当作歌手 ID；头像继续进入 ArtworkCover 的同一账号封面缓存。
- `musicLibrary.js`：App 拥有的云端收藏与歌单编辑控制器；所有收藏读取、绑定与写入共享队列，精确 listId/fileid 增删，服务端确认后发布。错误读回校验最终结果，读取失败保留快照但使后续写入先刷新；账号代次隔离迟到回调，批量操作每次最多 1000 条。
- 显式刷新、收藏和绑定的前置读取允许重试失败目录；初始化、就绪 watcher 和自动读回默认不重试，继续共享请求与账号代次。音乐库不提供一键清空收藏方法；移除只针对明确选择的歌曲条目。
- `hydrateFavorites` 仅接受显式账号匹配的只读快照，提供离线心形而不绑定云端写入目标或触发同步；首次云端确认后不再接受缓存覆盖，清空账号会话才重置此保护。`librarySongKey` 以来源、云盘账号和规范 hash 标识队列曲目，同 hash 的云盘与曲库歌曲互不合并。
- `listeningHistory.js`：以真实播放采样累计有效收听时间，按播放实例限定一次历史上报；跳转/缓冲/暂停不计时，换质保留实例，失败仅在当前实例内有限重试。同步开关只暂停计时并取消请求和重试，保留已发起记录，避免取消结果未知时重复上报；未上报的实例重新开启后只累计开启期间的播放时间，账号变化或新播放才清除旧实例。
- `musicSharing.js`：生成歌名、全部歌手和专辑文字，只附加接口已给出的公开酷狗页面；过滤音源、云盘和含认证字段的链接，缺少公开链接时保留纯文字。
- `desktopLyrics.js`：桌面歌词纯解析器，输出统一毫秒时间轴，支持 KRC 词级时序、LRC 重复时间标签、正负 offset 和 UTF-8 翻译，保留原始空格、Unicode 与文本尖括号。
- `lyricProcessing.js`：为显示生成歌词副本，使用 OpenCC 双向简繁转换、Intl 中文分词及基础中英文脏词遮罩；整句处理后分配回原 KRC 词区间，保留所有时间标签。读取来源提供的日文罗马音，按毫秒时间轴、重复标签和 offset 对齐。
- `songMetadata.js`：读取歌曲 VIP 徽标，兼容既有 `privilege` 的 8/10 数值与字符串、大小写字段和明确 VIP 标志；按歌曲、歌手、专辑的历史字段过滤歌曲，保留原数组与行对象。
- `songMetadata.js` 的 getSongSearchKeyword 优先读取明确曲名，再兼容 name/filename/FileName；识别已知单人或多人歌手前缀，保留标题中的连字符和版本后缀，文件名去除音频扩展名，空或非文本名称不生成关键词。
- `songMetadata.js` 的 getSongArtists 将可用歌手数组规范为独立 `{ id, name }`，兼容历史歌手/作者字段并去重；空数组不遮蔽其他数组，结构化姓名保持原样，缺失数组时仅按顿号和带空格斜线拆分合唱文本，单个歌曲级歌手 ID 不分配给多个人。

## 核心流程

- 设置应用调用 `applyTheme()`；system 模式监听系统变化，离开该模式时移除监听。
- 主题数据与校验统一在 `themes/`；切换整包重置视觉变量，并同步根元素 theme/themeBase 和 colorScheme。主窗口高级 CSS 经目录编译后只替换唯一 style，切回无 CSS 主题则删除；预览独立于持久化，在会话广播期间保持，取消后解析最新保存设置。导出包括主/桌面 CSS，不读取非视觉设置。
- 外观恢复先应用安全的内置主题预览，再经设置事务持久化；失败保留预览供重试，成功后才取消。ThemeRecovery 负责流程，NotificationRoot 的统一通知宿主通过主题安全标记与 Shadow DOM 隔离高级 CSS；themeManager 不创建恢复面板或消息样式。
- `mergeDeep()` 原地合并对象、替换数组，undefined 字段表示删除。
- `replaceReactive()` 保持目标引用并移除来源中不存在的旧字段。
- 菜单打开时注册稳定关闭回调，关闭或卸载时取消注册。
- logger 对控制台、内存和 IPC 使用同一可序列化脱敏快照。
- App 通过 initializePlaylistCacheSession 设置账号；播放器和封面使用 waitForPlaylistCacheSession / callPlaylistCache 等待最新初始化。无桌面桥接或会话初始化失败时回到在线路径；迟到媒体能力不交给新账号，已取得的租约会释放。
- 尾静音分析读取受租约保护的完整 `bk-cache` 文件，每声道分别检查末尾至多 15 秒且不超过总长 10% 的区间；50ms 块须同时满足 RMS ≤−65dBFS、峰值 ≤−55dBFS，并连续到结尾至少 1.5 秒。需在窗口内（含一块边界保护）确认从有声到静音，否则保守正常播完；保留 250ms 静音后才给出跳过时间。解码和媒体时长差超过 100ms、不支持格式、全静音或超限均不跳；扫描分块让出界面线程，原始 PCM 不受用户静音或过渡音量影响。
- MusicPlayer 通过 `parseDesktopLyrics(content, rawData)` 生成桌面歌词；翻译先按原始有效歌词行关联，再展开重复时间标签与排序。正 offset 提前歌词，截到零点时同步校正词开始/结束与持续时间；KRC 无词标签时使用整行时长。可选翻译损坏仅忽略译文，不丢弃原文，不在解析层拆分 Unicode 字符或解析 HTML。
- `processLyricContent(content, rawData, playback)` 只返回显示副本，原始在线/保存版本不被改写。`preferSimplifiedChinese` 决定简体或繁体，`segmentLyrics` 只增加相邻中文词间空格，`showProfanity` 关闭时按内置基础词表替换星号；不保证识别所有变体或绕写。日/韩文原文保留字形，中文译文独立处理。`readLyricRomanization()` 仅返回日文歌词中可用的拉丁发音，不推测缺失读音或把中文拼音当罗马音。

## 关键保障

- 对象写入前递归拒绝 `__proto__`、`constructor`、`prototype` 字段。
- 日志不保存请求配置和凭证；错误保留必要的类型、消息、堆栈、原因和状态。
- 日志限制嵌套深度、字符串长度与数组大小，处理循环引用。
- 日志桥接失败不影响业务，且避免重复输出桥接失败提示。
- 不额外创建平行的日志、主题、菜单或通知管理实现。工具把业务结果返回调用方，由 AppNotice 驱动原版 Fue 通知；主进程及歌词窗口经已校验的固定 IPC 转交同一入口，不添加独立 toast 工具或全局消息 store。
- 歌曲徽标不把未知权限码、音质/文件大小或账号会员状态推断为 VIP；只提供展示元数据，不声称实际可播放或修改权限。
